# ADR-0002: EdDSA / Ed25519 for all signatures

- **Status:** accepted
- **Date:** 2026-11-10
- **Deciders:** team

## Context
We sign identity credentials, access tokens, DPoP proofs and attestation evidence. We want a single algorithm that is modern, fast, and hard to misuse.

## Decision
Use **Ed25519** (EdDSA, RFC 8037) everywhere. Verifiers **pin** `algorithms=["EdDSA"]`. Library: PyJWT with `cryptography`.

## Alternatives considered
- **RS256.** Large keys, and the classic alg-confusion pitfalls with HS256.
- **ES256.** Fine, but ECDSA needs good randomness for every signature and is easier to get subtly wrong.
- **HS256.** A symmetric secret would have to be shared with every verifier, so it can't provide possession.

## Consequences
- **Gained:** one key type and small keys. JWK thumbprints are simple (`crv`, `kty`, `x`).
- **Must do:** tests must cover the `alg=none` and HS256 downgrade attempts being rejected.
